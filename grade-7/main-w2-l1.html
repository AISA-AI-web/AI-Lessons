Core · Part 1 of 3

The three-stage shape

Why does the order matter?

Previously

Words to know

Tap a card to flip it and reveal the meaning.

Input, process, output

Look inside almost any AI tool and you find the same three stages. First an input goes in – the text you type, the photo you choose or a number. Then a process changes it – this is the part you cannot see. Last, an output comes out – a label, a guess or something new.

The arrows only point one way, so the order matters. A classifier is a workflow whose output is a label, like ‘desert’ or ‘cat’. For a classifier the same input always gives the same output – it is deterministic; the answer only changes if the input changes. (Generative tools that sample can vary, but that is a different kind of AI.) Once you can spot the three stages, you can explain how any tool works.

Core · Part 2 of 3

Trace a worked example

Which piece plays which part?

Follow one item through

Tracing means following one piece of data through each stage and naming what happens to it. Once you can spot the three stages, you can explain how any tool works – from a photo filter to a translation app.

Each part of a workflow has a job: the input is what goes in, the process is where a learned model does its work, the model is the patterns it learned from many examples, and the output is what comes back.

Why it matters

AI apps used across the UAE – from Arabic-English translation to smart parking sensors – all follow input, process, output. Knowing the shape lets you understand and question the tools around you.

Core · Part 3 of 3

The process is not magic

So can you trust every output?

It matches, it does not think

The process stage can feel like magic, but it is not. Inside, a model has learned patterns from many past examples, and it uses those patterns to turn your input into a likely output. It does not think or understand – it matches.

That is why an input that is unusual or unclear can lead to a strange output, and why you check the output instead of trusting it straight away. Using the words input, process and output correctly helps you say exactly where a problem could enter.

Cross-curricular link · Geography

In Geography, a river system has the same three stages: rainfall enters as the input, erosion and transport are the process, and deposition of sediment is the output. Trace one water drop through the stages just as you trace one item of data through an AI workflow.

Lab · Part 1 of 3

Build and trace

How do you build the three stages?

Trace one item

Tracing means picking one item and following it all the way through. You watch it go in as the input, see what the process turns it into, and read what comes out as the output. Writing down each stage for the same item keeps you honest – it stops you from mixing up two different items. A clear trace is how testers prove they know what a workflow really does, not just what they hope it does.

In Teachable Machine the example images you add are the input, clicking Train is the process, and the label with its confidence score is the output. Building the stages in the right order is what lets you trace them.

Lab · Part 2 of 3

Change the input

Same process – so why did the output change?

Compare the outputs

Here is the tester's trick: keep the process exactly the same and change only the input. Run it again and compare the two outputs. If the output changes, that tells you the process is responding to its input – which is what it should do. A small change in input can cause a big change in output.

Some actions change the output because they change the input the model sees; other actions, like re-running the very same image, leave the output the same.

Why it matters

Testers who change inputs on purpose find problems before real users do. This is how teams in the UAE check an AI service behaves fairly before it is switched on for the public.

Cross-curricular link · Design & Technology

In Design and Technology, you test a product by changing only one variable – such as the material – while keeping the method the same, then compare the results. That is exactly the tester's trick: change only the input and compare how the output changes.

Lab · Part 3 of 3

Find the weak spot

Where could an error sneak in?

Black box and verify

A black box means you can see the input and the output but not the reason inside. Teachable Machine shows a confidence score next to each label (for example 0.90 = 90%), but it does not tell you why it chose that label – and a high score is not proof the answer is correct.

That is why testers ask where an error could enter: a poor input, a process trained on too few or too narrow examples, or an output trusted without checking. Before you rely on any output, verify it against something you know is correct.

Lab · Hands-on mission · Worksheet

Systems Detectives: build, change, verify

Build a small three-stage workflow, trace one item through it, then change only the input and compare how the output behaves – ending with a verify step.

Tool for this week: Google Teachable Machine (teacher-operated)

1. As a class, name the three classes (for example: open hand, fist, thumbs-up). 2. Direct the teacher to add about 15 balanced, varied example images to each class, using the webcam pointed at objects or hands only. 3. Click Train – these examples are the input, training is the process. 4. Test in Preview with a new, unseen example and read the confidence output aloud. 5. Trace the full input → process → output path on the board and label each stage. If it is wrong, add better or more examples, keep the classes balanced, and re-train.

Stay safe: the teacher operates the tool on the board and students never log in. Teachable Machine trains in the browser and the samples stay on the teacher's device. Use objects, hand gestures or drawings only – never faces, voices or names. Clear the project at the end of the lesson. No live demo? Use the simulated-AI card deck: run a ‘human classifier’ – agree a rule from example cards, then test it on new cards.

Let's try it

  1. Set up your three stages: input, process and output.
  2. Send one item through and write what happens at each stage.
  3. Change just the input and send it through again.
  4. Compare the two outputs – what changed?
  5. Explain why the output changed even though the process stayed the same.
  6. Check one output against a trusted answer before you trust it.

Reflect · Responsible use & human in the loop

The AI tool does the sorting, but a person stays in charge. A person chooses the classes and examples, checks the outputs, and decides what to do with them.

Lesson summary

You found the three stages – then built a workflow, tested it and found where an error could enter

Key ideas to remember

  • Every AI workflow has three stages in order: input, process, output.
  • Tracing means following one item through each stage in turn.
  • The process matches learned patterns – it does not think or understand.
  • A wrong or unclear input can lead to a wrong output, so we check it.
  • Keep the process the same and change only the input to see what the process does.
  • A high confidence score is not proof the output is correct – an error can enter at the input, the process or the output, so verify before you trust.

Glossary

Input
the data that goes in, such as text, a photo or a number.
Process
what happens inside: a trained model or set of rules changes the input.
Output
what comes out: a label, a prediction or new content.
Trace
to follow one piece of data through each stage.
Test
to try an input on purpose to learn how the workflow behaves.
Verify
to check an output against a trusted answer before trusting it.
Black box
a process whose inside we cannot see, only its inputs and outputs.
Confidence score
a number showing how sure the tool is – not proof it is correct.
