Week 0 Foundation · Part 1 of 3

The big ideas

How does a model learn – and what does it keep?

1

Rule-based vs learned

A rule-based system does exactly what a person wrote: if metal → Recycle. A learned model is shown many labelled examples and adjusts numbers inside (its parameters) until it predicts well – nobody writes the rule by hand. Many real systems mix both.

2

Training vs inference

Training is the one-off teaching phase: the model sees labelled examples and updates its parameters. Inference is every later use: the finished model labels a new input without changing.

3

What a model stores

A trained model does not keep copies of the training photos or sentences. It stores patterns as parameters. That is why it can answer about new inputs but cannot show you the originals.

4

Determinism & confidence

A classifier is deterministic: the same input gives the same output and the same confidence every time. A confidence score (e.g. 0.90) says how sure the model is about this answer – it is not the same as accuracy, and a confident answer can still be wrong.

5

Train/test split

To check a model really learned (rather than memorised), hold back some labelled examples as a test set and measure accuracy only on those unseen items.

Week 1 · Part 1 of 3

The three-stage shape

What goes in, what happens, what comes out?

Words to know

Tap a card to flip it and reveal the meaning.

Today we launch a new unit. AI tools follow a shape you already know from everyday machines: something goes in, something happens, and something comes out.

AI is a workflow

Think about a vending machine. You choose a drink (input), the machine works inside (process), and your drink drops down (output). AI works the same way. You give it something to start, it runs steps using a model that learned from many examples, and it gives you a result. When you can spot the input, the process and the output, you can understand almost any AI tool – and later you will build your own simple workflow.

Where the analogy breaks: a vending machine follows fixed rules a person wrote, so it always does exactly the same thing. An AI model is different – it has learned its patterns from many examples rather than from rules typed in by hand. Use the vending machine only to see the input-process-output shape, not to explain how the AI ‘decides’.

Think about it

A classifier gives the SAME output every time you give it the same input; that is what makes it a classifier. Only generative AI that samples is designed to vary. So if you re-run a build and the answer changes, what actually changed – the input, or the tool you used?

Week 1 · Part 2 of 3

Ask sharp questions

When is an answer worth trusting?

A confident answer can still be wrong

AI outputs can look neat and sure of themselves, but that does not make them true. The model is guessing patterns, so it can get things wrong. That is why we verify before we trust: we check the output against the task and a source we trust before we use it.

A Systems Detective asks sharp questions about how a tool decides – what goes in, what the process does, and how to check the result – rather than accepting an answer just because it sounds confident.

Why it matters

Across the UAE, AI helps with things like translating signs for visitors, sorting recycling, and answering questions at government service desks; spotting the input, process and output helps you understand and question the tools around you.

Week 1 · Part 3 of 3

Our safe-use charter

What makes a rule keep us safe?

Responsible use

Responsible use means using AI safely and fairly. We keep ourselves safe: no real names, faces or private details go into any tool, and an adult always runs the tool for us.

We also check results instead of trusting them blindly. Today the class agrees a safe-use charter – a short list of rules everyone can follow – and adds new words to the vocabulary wall.

Lesson summary

You learned how models learn, launched the unit and started thinking like a Systems Detective

Key ideas to remember

  • A rule-based system follows steps a person wrote; a learned model adjusts its parameters from labelled examples.
  • Training teaches the model once; inference is every later use. A classifier gives the same answer and confidence for the same input – and confidence is not accuracy.
  • Every AI tool follows the same shape: input, then process, then output.
  • The process uses a model that learned patterns from examples – it does not think like a person.
  • A confident-looking output can still be wrong, so we verify before we trust.
  • A strong responsible-use rule is clear, keeps data private, and can be followed.

Glossary

Input
what you give the system to start, like a question or a photo.
Process
the steps inside that change the input into something new.
Output
what the system gives back to you at the end.
Model
the part of an AI that has learned patterns from lots of examples.
Responsible use
using AI safely and fairly, with no personal data and always checking the result.
