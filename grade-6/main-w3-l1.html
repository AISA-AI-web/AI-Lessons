Core · Part 1 of 3

The prompt frame

What turns a vague ask into a task?

Previously

In Week 2 you saw how a learning system builds a model from data. Many AI tools are learning systems – so the words you give them really shape what comes back.

Words to know

Tap a card to flip it and reveal the meaning.

Goal, Context, Format

A vague prompt like ‘tell me about the desert’ leaves the tool guessing. So it often hands back something off-target. A structured prompt tells it exactly what to do.

Goal: what you want done. Context: the details it needs. Format: how the answer should look. Together they make the task far more likely to be completed.

Core · Part 2 of 3

Name the structure

Which parts really belong in a prompt?

Structure vs clutter

Many AI tools are learning systems, so the wording strongly shapes the result. A structured prompt narrows the possibilities. That makes the task far more likely to be completed.

If you can name the parts you used, you can say whether the task was completed and why. Some things belong in the prompt. Others are just clutter – or unsafe.

Core · Part 3 of 3

Change one thing

How do you improve a prompt safely?

Check, then improve

Once you get an output, compare it to the task. Did it do everything you asked? If not, change one thing in your prompt and run it again.

Two safety rules stay switched on the whole time: never put personal data in a prompt, and always verify the answer – a confident output can still be wrong.

Core mission · Worksheet

Prompt detectives: frame, judge, improve

Write a structured prompt for a real, non-personal task, judge whether it completed the task, and improve it once.

Let's try it

What you need: a Goal-Context-Format prompt frame, a defined task card, a pencil and the class board.

  1. Read the defined task and underline what ‘complete’ means for it.
  2. Write a structured prompt with a Goal, Context and Format.
  3. Hand your prompt to the teacher to run on the approved tool.
  4. Judge whether the output completed the task, and say why.
  5. Make one adjustment to your prompt to complete it more fully.
  6. Verify the output against the task and run a quick risk check.

Tool for this week: the approved AI tool, run by the teacher

You write your prompt on paper. The teacher types it into the school-approved AI tool on the board – students do not log in. Stay safe: use a non-personal task only; never put personal data (names, addresses, photos) in a prompt; always verify the output against the task – a confident output can still be wrong. No live tool? Use simulated-AI cards – pre-printed outputs for a vague prompt and a structured one – so pairs still practise framing, judging and improving.

Lab · Part 1 of 3

Compare structures

Which structure completes a richer task?

Compare, then reuse

A richer task has several requirements. A weak prompt structure leaves parts unfinished. Run two structures on the same task and compare: which one completes it, and which one is more accurate?

Gathering that evidence beats guessing. You can see which design is stronger before you decide to reuse it.

Lab · Part 2 of 3

Design a template

How do you turn a winner into a tool?

From winner to template

Turn the stronger structure into a reusable template. A template is a prompt with labelled slots you can fill in for any similar task – like ‘summarise any short text for a younger reader’.

This is real solution design. You are not just wording one request – you are building a tool others in your class can reuse.

Lab · Part 3 of 3

Build in the checks

What must every template force you to do?

Build in the checks

Outputs can be confidently wrong. So every good template forces two checks: verify the output against a reliable source, and run a risk check for personal data and errors.

No template ever asks for personal data. This is how real AI solutions are designed – and it is the foundation for your signature activity in the coming weeks.

Lab mission · Worksheet

Template designers: compare, build, check

Complete a richer task with two structures, compare them, then design a reusable template with the checks built in.

Let's try it

What you need: a reusable template skeleton with labelled slots, prompt cards, a defined richer-task card and a pencil.

  1. List the three requirements of the richer task.
  2. Draft two structured prompts that order Goal, Context and Format differently.
  3. Predict which structure will complete the task more fully.
  4. Watch the teacher run both prompts and record the outputs.
  5. Mark which requirements each output met and verify the facts.
  6. Turn the stronger structure into a reusable template with labelled slots.
  7. Build a verification step and a risk check into the template.

Tool for this week: the approved AI tool, run by the teacher

The teacher runs both of your prompts on the school-approved AI tool on the board – students do not log in. Stay safe: no template ever asks for personal data; verify every output against a reliable source; run a risk check for personal data and errors before anything is used. No live tool? Run the unplugged prompt-card workshop – arrange Goal-Context-Format cards into two structures, match them to curated printed outputs, then design your template on paper.

Lesson summary

You structured a prompt, judged and improved it – then compared structures and built a reusable template with the checks built in

Key ideas to remember

  • A structured prompt states a Goal, Context and Format, so the task is far more likely to be completed.
  • A vague prompt leaves the tool guessing and often returns something off-target.
  • Judge the output by comparing it to the task, then change one thing to close the gap.
  • A richer task has several requirements – run two structures and compare completion and accuracy. Evidence beats guessing.
  • A reusable template is a prompt skeleton with labelled slots for a whole group of similar tasks.
  • Every good template forces a verify step and a risk check. Never put personal data in a prompt – a confident output can still be wrong.

Glossary

Goal
what you want the tool to do.
Context

Format

Structured prompt
a prompt that states a clear goal, context and format.
Template

Reusable
able to be used again for many similar tasks.
Verify
check an output against a reliable source.
Risk check
a quick check for personal data and errors before use.
